# Customer Churn Analysis: SQL & Power BI

## Project Overview

This project analyzes 13,000 customer records to understand customer churn and behavior. SQL was used for data cleaning, exploration, and analysis, while Power BI was used to create an interactive dashboard. The analysis focuses on customer demographics, tenure, contract types, payment methods, monthly charges, and satisfaction levels. It helps identify important churn patterns and customers who are more likely to leave. The insights from this project can help businesses improve customer retention, reduce churn, and make better data-driven decisions.

---

## Key Skills & Tools Used

* **Power BI** : Data visualization, dashboard development, DAX, Power Query, KPI cards, slicers, and interactive charts.

* **SQL** : Data cleaning, data analysis, filtering, aggregation, CASE statements, GROUP BY, and customer churn analysis.

* **Data Analysis** : Customer churn, retention analysis, tenure analysis, satisfaction analysis, payment method analysis, and customer segmentation.

---

## Key Findings & Insights

* The dashboard contains **3K customers**, with **568 churned customers** and approximately **3K retained customers** based on the selected dashboard view.

* The overall **Churn Rate is 17.4%**, providing a quick view of the current customer attrition level.

* Customers are analyzed based on different **payment methods**, helping identify which customer groups contribute more to churn.

* The **satisfaction level** analysis shows differences in churn across Low, Medium, and High satisfaction categories.

* Customer churn is also compared by **gender**, providing a view of how churn is distributed between female and male customers.

* The **tenure group analysis** compares churn across different customer relationship periods, including 0–12 months, 13–24 months, 25–48 months, and 49+ months.

* The dashboard also tracks **Total Charges**, which helps understand the financial value associated with the analyzed customer base.

---

## Trend & Performance Analysis

* **Monthly Churn Trend** is used to understand how customer churn changes across different months.

* **Churn by Payment Method** helps compare churn levels across different payment-related customer groups.

* **Churn by Satisfaction Level** provides insights into the relationship between customer satisfaction and churn.

* **Churn by Gender** shows the distribution of churn between female and male customers.

* **Churn by Tenure Group** helps identify how customer retention changes based on the length of the customer relationship.

* Interactive **Year and Gender slicers** allow users to filter the dashboard and explore the churn data from different perspectives.
